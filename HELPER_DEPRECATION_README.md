# amadeus helper deprecation review

Reviewed: 2026-10-08 (helpers), 2026-10-09 (file organization), 2026-10-13 (recursive R audit).

**Status:** proposals only. No public helper is proven ready for immediate removal. Runtime checks were unavailable (`libRblas.so`/recorded container limitations); **G6 is UNKNOWN for every candidate**. No external-provider behavior or downstream compatibility was verified.

## Scope and safeguards

- Inspected all 10 recursive `.R` files under `R/`, callers, tests, manuals, vignettes, exports and workflows. The reference index preserves evidence. No `.Deprecated()`/`.Defunct()` calls or explicitly defunct API were found.
- Exports remain public despite `@keywords internal` or pkgdown exclusions. Static searches do not rule out dynamic lookup, downstream `:::` calls or manual sourcing; external users/reverse dependencies are unaudited.
- [`.Rbuildignore`](../.Rbuildignore) excludes `R/ignore.R`, `tests/` and `tools/`; verify source tests and installed artifacts separately. The checkmate pilot concerns assertions, not helper retirement.

## Deprecation criteria

- **Redundant:** equivalent supported behavior is demonstrated; prefer a shared private implementation behind existing public wrappers.
- **Obsolete:** a superseding workflow, documented migration path and real maintenance benefit exist.
- **Unused private code:** confirm no callers, exports, dynamic entry points, documentation promises or manual users.
- **Abandoned experiment:** confirm ownership and lack of active use before archiving build-excluded code.
- **Replacement:** label it exact, adapter-backed, limited, or unavailable. Do not present a workflow alternative as a drop-in replacement.
- **Scientific compatibility:** preserve values, units, missingness, time grouping, CRS, spatial matching and output schema. Separate intentional corrections.
- **Dependencies:** remove a package only after its last supported use disappears; shorter code or a newer dependency alone does not justify migration.

## Decision gates

Record **PASS / FAIL / UNKNOWN / NOT APPLICABLE** with evidence. UNKNOWN does not pass; never weaken tests to advance a migration.

| Gate | Required evidence | Outcome |
| --- | --- | --- |
| G0 — Scope | Helper, owner, public/build status, supported behavior and benefit. | Agree the proposed action. |
| G1 — Usage | Repository, released documentation, downstream and manual-use review. | Identify callers and unresolved risks. |
| G2 — Baseline | Input/output, metadata, condition, visibility and side-effect tests. | Establish actual behavior. |
| G3 — Replacement | Paired tests and independent scientific fixtures; explain every difference. | Refactor only proven-equivalent behavior. |
| G4 — Migration | Updated callers, examples, limitations, NEWS/Rd and support window. | Publish guidance; retain entry points. |
| G5 — Warnings | Approved class, wording, frequency and timing, with tests. | Enter the announced warning stage. |
| G6 — Verification | Source tests, installed exports, documentation diffs and platform checks. | Release the validated stage. |
| G7 — Retirement | Support window completed, known users migrated, final audit and maintainer approval. | Remove in the announced breaking release. |

- Public retirement uses G0–G7. Private refactoring uses G0–G3 and G6; private removal also requires a final usage/artifact audit.
- No replacement: explicitly approve/document functionality loss at G3; do not claim equivalence.
- New warnings are observable changes. Preserve `download_run()`'s existing warning policy unless separately approved.
- Calendar time alone does not satisfy a retirement gate.

## Auxiliary-file consolidation assessment

**Retain the three shared helper files; move selected dataset-specific definitions only after equivalence checks.** Relocation is not deprecation or deduplication and establishes no runtime/memory improvement.

The actual calculation pair is `R/calculate_covariates_auxiliary.R` → `R/calculate_covariates.R`; this checkout has no corresponding `calculate_auxiliary.R` / `calculate.R` pair. The assessment also covers `R/manipulate_spacetime_data.R` (the actual filename), `R/process_improve_sites_builtin.R` and build-excluded `R/ignore.R`. Inventory counts below cover all top-level function definitions in these six files, including definitions whose `function` starts on the next line; nested functions remain part of their enclosing helper. This is a complete inventory for these six helper files, not a claim to enumerate every local helper embedded in the main dataset files.

### Evidence and boundaries for this removal batch

- **Twenty skip branches versus two warning-only flags:** GEOS and IMPROVE can reach the downloader even for FALSE, while the other 20 downloaders return before transfer. Early returns may still perform remote discovery, checks or directory creation; these are not uniformly side-effect-free dry runs. NEWS.md's statement that both flags are ignored conflicts with this snapshot.
- **Certificate settings:** NEI's old certificate values only affect a warning, not request configuration. Omission preserves existing transport configuration; no custom trust-store replacement is proven.
- **Grouping:** `.by_time` accepts temporal unit tokens (`R/calculate_covariates_auxiliary.R:1102–1140`), not arbitrary columns. NEWS.md:16–19 describes spatial `.by`, which is now rejected. Keep sys.call inspection so partial argument matching cannot silently reinterpret it.
